Evaluating TLS security configurations with machine learning

Can a simple model look at how a website's TLS is set up and say whether it's secure or vulnerable? I built the dataset, the classifier, and a tool to test it on live sites.

  1. Described each configuration with 25 TLS features
  2. Trained a logistic regression classifier
  3. Stress-tested it by adding noise to the inputs
  4. Built an OpenSSL-based probe for live servers
