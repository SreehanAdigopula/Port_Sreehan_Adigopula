This is my personal portfolio website, showcasing my work in cybersecurity, machine learning, and software development, along with my experience, recognition, and technical skills.

## Website features

- Responsive layout for desktop and mobile.
- Light and dark themes with a saved preference.
- Interactive Three.js background and animated page elements.
- Sections for projects, experience, awards, skills, and contact links.

## Technology

Built with HTML, CSS, and vanilla JavaScript in a single file, `REAL_PORTFOLIO.html`. Three.js is loaded from a CDN, and typography is provided by Google Fonts. There is no build step or package installation.

## Run locally

Clone this repository and open `REAL_PORTFOLIO.html` in a modern web browser:

```bash
git clone https://github.com/SreehanAdigopula/Port_Sreehan_Adigopula.git
cd Port_Sreehan_Adigopula
```

Alternatively, start a local server from the repository folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000/REAL_PORTFOLIO.html.

An internet connection is needed to load the external fonts and Three.js.

## Editing and hosting

The page content, styles, and scripts are all inside `REAL_PORTFOLIO.html`. Update that file to change project details, links, colors, or interactions.

To serve the portfolio at the root URL on a static host such as GitHub Pages, use `index.html` as the entry filename. This repository currently keeps the portfolio as `REAL_PORTFOLIO.html`; pushing the source alone does not enable GitHub Pages.
